# LP Monitor — Orca Whirlpools

Монитор концентрированных LP-позиций на [Orca](https://www.orca.so) (Solana).
Вбиваешь паблик-адрес кошелька — получаешь полную картину по каждой позиции
и симулятор ребаланса.

## Что показывает

**По каждой позиции:**
- Пара, тир комиссии, статус (в диапазоне / вышла из диапазона) с визуальной шкалой
- Текущий состав (сколько токенов A и B), стоимость в USD
- **Pending yield** — несобранные комиссии и реварды (точный расчёт через
  официальный Orca SDK по данным ончейн)
- Оценка APR позиции: доля в активной ликвидности пула × комиссии пула за 24ч
- **PnL** по истории транзакций позиции:
  - вложено (историческая USD-оценка на момент депозита),
  - собранный доход и выведенный принципал,
  - итоговый PnL и PnL против HODL (учитывает импермалосс),
  - реализованная годовая доходность, сетевые комиссии
- Статистика пула: TVL, объём и комиссии за 24ч

**Симулятор ребаланса** — «что будет, если сдвинуть диапазон»:
- требуемый свап для нового соотношения токенов,
- издержки: комиссия пула за свап + сдвиг цены (price impact) + сетевые сборы —
  это мгновенный убыток от действия,
- новая позиция: состав, концентрация ликвидности, прогноз дохода в день и APR,
- окупаемость издержек ростом доходности (break-even в днях).

## Запуск

```bash
npm install
npm start          # веб-интерфейс на http://localhost:3000
```

CLI-режим:

```bash
npm run cli -- <адрес-кошелька>                # обзор позиций
npm run cli -- <адрес-кошелька> sim 60 90      # + симуляция ребаланса в диапазон 60–90
```

## RPC

По умолчанию используются публичные эндпоинты (медленно, но работает):
`api.mainnet-beta.solana.com` + `solana-rpc.publicnode.com` для истории.
Для быстрой загрузки задай свой RPC (Helius / QuickNode / Triton):

```bash
SOLANA_RPC_URL="https://mainnet.helius-rpc.com/?api-key=..." npm start
```

Читаются только публичные данные — приватный ключ нигде не нужен,
приложение ничего не подписывает и не отправляет.

## Как считается

- Точная математика CLMM — через `@orca-so/whirlpools-core` (WASM-порт
  ончейн-программы): состав позиции, несобранные комиссии/реварды, котировки
  ликвидности.
- История позиции восстанавливается из транзакций аккаунта позиции:
  инструкции Whirlpool распознаются по дискриминаторам, потоки токенов —
  по вложенным переводам в/из волтов пула (точная атрибуция, даже если в одной
  транзакции несколько позиций).
- Историческая цена входа восстанавливается из соотношения внесённых сумм
  (обратная задача из формул ликвидности); USD-оценка точна для пар со
  стейблкоином (USDC/USDT/…).
- Прогноз дохода: `комиссии пула за 24ч × доля позиции в активной ликвидности`.
  Это оценка — предполагает сохранение объёмов и цены в диапазоне.

## Ограничения

- Прогноз APR опирается на статистику за 24ч — волатильность объёмов меняет картину.
- Оценка price impact для свапа не учитывает пересечение тиков (для крупных
  свапов реальный импакт выше — используй агрегатор).
- История разбирается по последним 40 транзакциям позиции (настраивается в
  `src/config.ts`).
- Пулы, отсутствующие в Orca API (нелистинговые токены), показываются без
  USD-оценок.
