# Вкладка «Рынок» — полезная инфа по LP

Дата: 2026-08-05. Статус: одобрено Алексеем (вариант A).

## Цель

Новая вкладка в веб-UI с рыночной информацией для принятия LP-решений:
волатильность, цена, тренд и вердикт бота по SOL. Карточки других монет
(ETH, BTC, ORCA, JUP) — заглушки «Не заполнено» под будущее наполнение.

## Бэкенд (src/server.ts)

`GET /api/market` — без параметров. Ответ:

```json
{
  "fetchedAt": 1754000000000,
  "coins": [
    {
      "symbol": "SOL", "filled": true, "product": "SOL-USD",
      "price": 150.1, "change24hPct": -1.2, "change7dPct": 4.3,
      "vol24hPct": 3.1, "vol48hPct": 2.9, "vol7dPct": 3.5,
      "verdict": "ok" | "storm" | "cooldown",
      "recommendedRangePct": 12,
      "volPausePct": 5, "volResumePct": 4
    },
    { "symbol": "ETH", "filled": false },
    { "symbol": "BTC", "filled": false },
    { "symbol": "ORCA", "filled": false },
    { "symbol": "JUP", "filled": false }
  ]
}
```

- Данные: `fetchHourlyCandles("SOL-USD", 7)` + `realizedVolDaily` из
  `src/lib/candles.ts` — те же формулы, что в боте, цифры совпадают.
- Вердикт по порогам бота: vol48h > VOL_PAUSE (5 %/день) → `storm`;
  vol48h < VOL_RESUME (4 %/день) → `ok`; между → `cooldown`.
  Пороги и ширина диапазона читаются из тех же env-переменных
  (VOL_PAUSE, VOL_RESUME, WIDTH_PCT, дефолты как в bot.ts: 5 / 4 / 12).
- Кэш ответа в памяти 10 минут (дисковый кэш свечей в candles.ts — свой, 6 ч).
- Ошибка Coinbase → карточка SOL приходит как `{symbol, filled: true, error}`,
  заглушки отдаются всё равно; HTTP 200.

## Фронтенд (public/index.html)

- Панель вкладок над контентом: «Позиции» | «Рынок». Переключение
  показом/скрытием блоков, без роутера; текущий контент уезжает в блок
  вкладки «Позиции» без изменений.
- Вкладка «Рынок»: грид карточек в текущей стилистике (.card, .kv):
  - SOL: цена, изменение 24ч/7д (цветом), волатильность 24ч/48ч/7д,
    бейдж вердикта (зелёный «можно в LP» / жёлтый «остываем» /
    красный «шторм — пауза»), рекомендуемый диапазон ±WIDTH_PCT%.
  - ETH/BTC/ORCA/JUP: приглушённые карточки «Не заполнено».
- Загрузка при первом открытии вкладки + кнопка «Обновить».
- Ошибка — в карточке SOL, остальное рендерится.
